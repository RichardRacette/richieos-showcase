How to play and demonstration limits

Select a connected misplaced group. Deposit it, or tap an open matching target. Select stored jewels to return them to the board. Correct jewels stay put; occupied targets never swap. Each completed color earns 12 tray spaces. Auto move fills a connected empty matching region; off moves one jewel.

Uses an inspected application engine with a newly created geometric fixture and a simplified view. This is not the original application. Photo conversion, imports, audio, saved progress, zoom, the library and device acceptance are omitted. No accounts or external requests.
